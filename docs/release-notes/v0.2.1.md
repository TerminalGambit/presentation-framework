# v0.2.1 — 2026-04-20

A consolidation release. Everything accumulated on `main` since `v0.2` is packaged here before the v0.3 milestone opens.

## Headline features

- **Presenter mode.** Split-view with current slide, next slide, speaker notes, and timers. Press `P` to open; windows sync via `BroadcastChannel`. Full walkthrough: [presenter-view.md](./presenter-view.md).
- **Animation system.** Five progressive-enhancement entry animations (fade / slide / scale / stagger / highlight pulse) wired through theme config; respects `prefers-reduced-motion`.

## Fixes

- PDF export no longer double-rotates portrait pages.
- Reveal fragments now sync via `postMessage`; `↓`/`↑` are the keybinds.
- Light-background theme presets get correct text color via the new `--pf-contrast-text` variable.
- Async SSE test flakiness eliminated with a timing guard.
- Animations demo's highlight-pulse slide uses the correct `left`/`right` two-column shape.

## Compatibility

No breaking changes to YAML, `metrics.json`, or the MCP surface. Existing decks rebuild byte-identical under the `default` theme.

## What's next

v0.3 is the **Post-CD Response** milestone: theme pack, full editable PPTX, MAF video spike. See `docs/SPEC.md`.
